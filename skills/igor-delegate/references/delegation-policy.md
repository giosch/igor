# Suitable tasks

Delegate local, bounded work such as one parser fix, a regression test, or a mechanical refactor with known callers. Include the smallest source tree that still reproduces the behavior and the tests.

Keep credential-dependent work, unrestricted network access, architecture decisions requiring broad context, and tasks without an independent verification method with the orchestrator. Security-critical changes need a qualified reviewer. Confirm that the selected source and docs are suitable for the configured endpoint. A remote OpenAI-compatible provider receives the prompt and tool results.
